# documents utilities

Tools for manipulating document files.


## Specification

Executable             |Description                                       |Extra Dependencies
:----------------------|:-------------------------------------------------|:-----------------
epub                   |Dumps HTML from an 'epub' e-book archive          |`zipinfo`, `unzip`, `w3m`
hugo-bump              |Bump the date in Hugo content files               |
hugo-date              |Print current date and time in the Hugo/Go format |
hugo-extract-timestamp |Extract a date/timestamp from Hugo content files  |
hugo-new               |Create a new Hugo post                            |
hugo-post              |Create a new Hugo post file                       |
hugo-timestamp         |Set a timestamp into a Hugo content file          |
